تطبيق عروض روافد الطاقة — طريقة النشر والتثبيت
================================================

أولًا: النشر مجانًا على GitHub Pages (مرة واحدة)
1) أنشئ حسابًا على github.com إن لم يكن لديك.
2) اضغط + أعلى الصفحة ثم New repository. اكتب اسمًا مثل: rawafed-quotes ، واختر Public ثم Create.
3) في صفحة المستودع اضغط "uploading an existing file"، واسحب كل محتويات هذا المجلد
   (index.html و manifest.webmanifest و sw.js ومجلد icons) ثم Commit changes.
4) Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← / (root) ← Save.
5) بعد دقيقة أو دقيقتين يظهر الرابط بالشكل: https://اسم-حسابك.github.io/rawafed-quotes/
   (الكود يكون عامًا، لكن لا توجد فيه أي بيانات؛ البيانات تبقى على أجهزتكم فقط.)

ثانيًا: التثبيت على الأجهزة
- أندرويد (Chrome): افتح الرابط ← القائمة ⋮ ← "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- آيفون (Safari فقط): افتح الرابط ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
- ويندوز (Chrome أو Edge): افتح الرابط ← أيقونة التثبيت في شريط العنوان.
- بعد أول فتح يعمل التطبيق بلا إنترنت. (حفظ الصورة PNG يحتاج إنترنت في أول مرة فقط.)

ثالثًا: تجهيز جهاز موظف جديد
1) على جهازك (مدير الشركة): أنشئ حساب الموظف من الإعدادات.
2) الإعدادات ← تنزيل نسخة احتياطية، وأرسل الملف للموظف.
3) الموظف يفتح التطبيق أول مرة ← "استيراد نسخة احتياطية" ← يدخل بحسابه.
   نصيحة: قبل تصدير النسخة لفرع، غيّر "رقم العرض التالي" إلى سلسلة خاصة بالفرع
   (مثلًا كركوك 10001، الانبار 20001) حتى لا تتكرر أرقام العروض بين الأجهزة.

رابعًا: تحديث الأسعار عند الفروع
- مدير الشركة أو مدير المبيعات: قائمة المواد ← "تصدير القائمة" ← أرسل الملف (واتساب مثلًا).
- مدير الفرع: زر "تحديث الأسعار" أعلى الشاشة ← يختار الملف.

خامسًا: تحديث البرنامج نفسه
- ارفع ملف index.html الجديد إلى نفس المستودع (فوق القديم)، فيصل التحديث لكل الأجهزة تلقائيًا عند فتحها بالإنترنت.
